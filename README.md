# Mridul Jain — Agentic AI Developer Portfolio

A dark-first, single-page static portfolio for Mridul Jain, presenting Agentic AI, Generative AI, RAG, Python, Azure, and backend engineering experience.

## Technology

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- Lucide Icons

## Local preview

No build or package installation is required. Open `index.html` directly in a modern browser, or use a static file server from the project folder.

## Deploy to GitHub Pages

1. Create a repository named `mriduljn4.github.io` for a user site, or create another repository name for a project site.
2. Push the contents of this repository to the `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. GitHub publishes a user site at `https://mriduljn4.github.io/`. A project site is published at `https://mriduljn4.github.io/<repository-name>/`.

## Alternative deployments

### Vercel

Import the GitHub repository. Choose the **Other** framework preset, use no build command, set the output directory to `.`, and deploy.

### Netlify

Import the Git repository. Leave the build command empty, set the publish directory to `.`, and deploy.
